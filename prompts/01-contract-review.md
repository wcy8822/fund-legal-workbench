# 合同首审 · 0.2.0-draft

遵守 shared.md。请站在资料包已确认的我方立场，对所选合同版本完成首轮审查。

用户补充：我方角色 {{our_role}}；交易/合同类型 {{contract_type}}；本次重点 {{focus}}。

先列交易事实卡：主体与身份、交易安排、主要义务、交割条件、期限、相关合同及附件。每项给原文位置和确认状态；把缺项列出来。不要根据基金法务身份就自行推定每份文件的我方角色。

按已批准且适用的审查标准检查，并补充材料能够支持的重大问题。只把真正适用的事项放入结论；投资金额、期限、控制权、退出、责任安排等均须根据实际合同出现的内容判断，不为凑清单添加条款。

输出：
1. 一句话结论：本轮最需关注什么，哪些信息尚不足。
2. 优先问题表：问题ID、合同/版本、条款、准确原文、问题类型、影响、依据类别及引用、建议、可接受替代的适用条件、待确认事项。
3. 待补材料/事实表：缺什么、为什么影响判断、需要谁提供（角色未知写待确认）。
4. 未覆盖事项：解析问题、未提供附件、未获确认口径与范围外事项。

“法律禁止”“公司不接受”“商业上不利”分别表述。风险等级需说明判断理由；缺证据时不要把猜测包装为确定违法。意见均为草稿，等待法务采纳。
