# 复核对方来稿 · 0.2.0-draft

遵守 shared.md。以明确选定的 {{baseline_version_id}} 为谈判比较基准，以 {{incoming_version_id}} 为本次来稿；本轮目标 {{negotiation_focus}}。不得默认以最早初稿代替本轮基准，也不得声称某版已发送给对方，除非有相应记录。

使用两版文本差异、相关全文、已确认谈判口径和合同级全部未结问题，分别回答：
1. 对方这次新改了什么，可能影响哪些义务、权利、条件或期限？
2. 我方旧问题哪些有调整迹象、哪些只部分响应、哪些没有解决？每条对应原issue/root、旧引文和新引文。
3. 修改是否影响关联定义、交割条件、付款起算、通知对象、附件引用或其他相关条款？仅检查相关范围并写明。
4. 哪些变化未被现有规则覆盖，需要人工另看？

输出表：变化/旧问题ID、旧原文、新原文、变化含义、建议接受/修改/不接受/待确认、建议依据、未决条件。建议只作草稿，不执行Word修订，也不改变意见状态。

对付款期限恢复的情形，最多写“已恢复，待法务确认”；通知对象、审批附件等其他事项独立判断。不要把没有改动的未决问题遗漏，也不能因没有命中规则就认定通过。
