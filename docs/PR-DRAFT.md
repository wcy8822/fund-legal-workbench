## 为什么需要这个变更

投资法务需要按项目找到合同初稿、当前稿与签署件，看到条款变动、未决问题、法源依据，以及哪份稿件已经被人工批准对外交付。现有 Word 工作习惯应继续保留。

## 本 PR 改了什么

- 本机单体 V0：项目列表与合同、审核意见、法源、交付物四入口；一条命令启动。
- 不可覆盖原件及版本、文本差异、可恢复归档、意见版本锚点与跨版本承接、人工结案、操作记录。
- 三份虚构投资协议验证“期限恢复，通知对象及审批附件仍未解决”；真实民法典565短引文/官方出处与合同约定分开。
- DOCX/PDF/MD 原件路径、保守解析和新建文本交付；内部清单与外部阅读稿分离；实际产物内部审阅包；人工批准及批准失效。
- 三个OpenAPI公司接口，默认禁用，支持项目scope、导入幂等、只下载有效批准对外件，不暴露存储。
- 离线Provider与可执行A/B盲测工具；Gemini/Claude尚未实际调用；调研、架构决策、V0/V1/V2门槛与交接文档。
