# V0.3：项目资料、公开法源与人工记录

日期：2026-11-21。分支：`feat/v0.3-evidence-retrieval`。状态：**代码已写入，尚未运行验证**。本轮仅研究公开文档，没有执行应用、语法检查、测试、浏览器自动操作、外部搜索 API 或模型调用。V0.1 历史通过记录不能证明本版本可运行。

## 1. 三类问题分别处理

| 使用者要做什么 | 本版路径 | 当前边界 |
| --- | --- | --- |
| 找本项目已有条款、意见和依据 | 法源 → 查当前项目资料 | 本地关键词检索，仅本项目已导入记录；不是语义搜索、公司全库或电脑索引 |
| 查当前或历史时点的公开法律依据 | 法源 → 查公开法源 | 独立输入抽象问题；准备官方跳转，或显式提交到已配置的搜索适配器 |
| 找公司制度、投委会材料、审批口径 | 连接与范围中显示未来连接器 | 未连接公司系统；没有推测账号、扫描目录或复制内部资料到公网 |

系统信息只显示本工作台能力配置、连接状态与检索记录。`available=true` 表示配置允许尝试，不证明网络、账号权益、配额或数据处理条件已验证。它不提供环境变量明文、机器秘密或其他已登录系统的探索入口。

## 2. 已写入的操作链路

1. 选定投资项目，进入“法源”，输入“解除 通知”等关键词查项目材料。默认检索当前合同版本、每个问题的最新记录、法源快照与各用途最新采用表达；可明确选择包含历史。多个空格分隔词按同时命中处理。
2. 阅读返回片段、合同版本或记录位置。文字片段不是原件完整解析；待 OCR/缺少文字的版本会列入覆盖提示。历史采纳不证明现在仍适用。
3. 如需外部依据，另开公开查询。问题初始为空，不自动复制合同、意见或本地命中；选择中国大陆、判断时点与用途，并确认去标识化。
4. 默认仅准备任务与官方入口；没有搜索接口也能继续人工查询。启用适配器后，只有明确点击“发送问题并联网检索”才尝试请求。查看历史、刷新记录和打字不触发联网搜索。
5. 候选记录标“搜索摘要，待核对原文”。法务打开原始网页后，另行录入准确引文、资料类别、公布/生效时间、效力状态和核验说明，确认原文、法域及判断时点。准确引文栏不会自动填入搜索摘要。
6. 保存为新的法源快照，记录人工确认时间、检索任务和候选 ID。之后沿已有意见入口选择该来源并填写准确引文。新来源不会自动改写旧意见、改变结案状态或批准外稿。

本版不会自动读取候选网页、判断法效、给出检索结论、生成法律建议或更新已有意见的依据。来源登记中的 `verified_at` 是人工确认操作时间，说明明确写明“应用未抓取原文”。公司有权审批者和公司制度版本不在本版身份模型中。

## 3. 公开搜索配置与出站内容

实现位于 `app/public_search.py`，采用现有 `httpx`，没有新增独立服务。选择 REST 是当前单体的实现取舍；专业法律 MCP 仍是可替换候选，未安装或调用。服务端环境变量如下：

| 配置 | 行为 |
| --- | --- |
| 未设置或 `FWB_PUBLIC_SEARCH_MODE=disabled` | 默认关闭；返回 `not_configured`，不外发 |
| `FWB_PUBLIC_SEARCH_MODE=keyless` | 使用 Tavily 官方无密钥模式；仍有第三方传输和限流，不等于数据授权 |
| `FWB_PUBLIC_SEARCH_MODE=api_key` | 从 `FWB_TAVILY_API_KEY` 读取服务端密钥；无密钥/格式不合适时不发请求 |

当前“先不验证”安排仍有效，不要因本说明列出配置就自动调用。任何真实项目外部处理仍须遵守 `AGENTS.md` 和 V1 数据处理门槛。API key 不放入前端、仓库、示例、日志或聊天。

提供方只接收**已确认的抽象法律问题、CN 法域、判断时点与公开检索参数**。不接收项目 ID/名称、合同内容、公司文件、内部意见、客户名或本地结果。请求模型拒绝额外字段。服务端对邮箱、手机号、身份证号、网址、已知项目/交易方名称及部分明显合同或凭据格式做有限预检；这不是完整 DLP，不能保证识别全部秘密或间接身份线索。

固定调用 `https://api.tavily.com/search`，限定 `npc.gov.cn`、`csrc.gov.cn`、`amac.org.cn`、`court.gov.cn`、`gov.cn` 及子域，最多保留8条候选。结果 URL 再校验 HTTPS、域名、凭据和敏感参数；不访问这些 URL。关闭提供方生成答案、原始网页内容与图片，不重试、不跟随重定向，不读取代理环境；响应最多1 MiB。域名过滤并不保证搜索召回完整或页面内容权威且适用，仍需阅读原文。

当前/历史适用检索不按发布日期剔除旧规则；“近期公布与更新”使用提供方最近一个月过滤，这不是施行时间过滤。搜索排名、网站更新时间与法律判断时点分别处理。发现新公布未施行文本、草案或解读时，应按其真实类别记录。

## 4. 状态、记录与证据保护

`research_runs` 固定请求；`research_outcomes` 追加一次执行结果；`research_adoptions` 关联人工来源记录。三类表均有禁止更新/删除的触发器。页面读取最近20次记录，单次 ID 仍可单独查询。公开网络请求在数据库事务外执行，避免长时间占有写锁。

| 状态 | 准确含义 |
| --- | --- |
| `prepared` | 只准备查询，没有执行搜索 |
| `not_configured` | 当前配置不能发起搜索，不等于没搜到依据 |
| `completed` | 当前搜索范围取得候选，不代表原文或适用性已核验 |
| `no_results` | 本次范围没有可用候选，不代表法律、案例或文件不存在 |
| `authentication_failed` / `rate_limited` / `error` | 执行受限或失败，与零结果分开 |
| `unknown` | 任务已保存但完成结果未保存，可能仍执行或中断；不假设未外发，也不自动重试 |

`sent_externally=true` 保守表示尝试过外部请求，不证明提供方实际收到；`null` 表示执行情况未知。原始提供方错误、凭据和响应正文不回传。候选 URL、摘要与人工准确引文分开存储；检索状态不能提升问题或交付状态。

录入来源须三项人工确认。候选必须属于该项目该次公开检索；本地命中不能直接从此入口转为法律依据。完全相同请求重复提交返回原记录；同一任务、同一候选内容变化返回409，要求追加新任务/来源，避免覆盖。人工独立来源可无候选 ID 录入。

新增来源沿用 `add_source` 更新项目审查版本，从而使旧意见改写快照及既有外稿批准需要重新复核。它不会覆盖旧文件、旧引文或旧来源，不会关闭意见。普通本机入口仍没有企业登录/RBAC；项目范围过滤不是公司级身份隔离证明。

## 5. 本机接口

以下均属本机工作入口，不是新增公司集成 API；既有三个公司入口继续保留。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/retrieval/capabilities` | 脱敏的配置状态、范围和未连接候选 |
| `POST /api/projects/{pid}/research/local` | `{query, include_history}`；本项目关键词搜索并追加记录 |
| `POST /api/projects/{pid}/research/public` | `{question, jurisdiction:"CN", as_of, purpose, deidentified_confirmed, mode}`；准备或显式搜索 |
| `GET /api/projects/{pid}/research/runs` | 最近20次完整记录 |
| `GET /api/projects/{pid}/research/runs/{rid}` | 项目范围内单次记录 |
| `POST /api/projects/{pid}/research/runs/{rid}/adopt-source` | 人工登记准确来源、可选候选关联与三项确认 |

`purpose` 为 `current_rules|recent_updates|as_of`，`mode` 为 `prepare|search`。登记字段与已有法源字段一致，增加 `candidate_id`、`human_confirmed`、`original_checked`、`as_of_checked`；`jurisdiction/as_of` 从任务继承，不能由新来源表单悄悄替换。`is_demo` 用于明确标记测试样例。类别和效力状态分别填写。
