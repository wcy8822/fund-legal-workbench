## 2. 前端检查的实际边界

前端脚本用临时数据库的实际API响应，执行渲染函数与状态分支。36项检查覆盖四入口、三稿引导、合同与意见显示、最新根问题/历史切换、引文锚点、批准有效性、内部审阅包、人工勾选、未结接受、HTML转义、链接协议与CSP无内联样式。

**这不是浏览器E2E。** 本环境尝试启动Chromium时返回 `process_singleton_posix: socket() Operation not permitted`，未运行浏览器点击、截图、键盘导航、焦点或响应式视觉验收；没有用公开部署绕过限制。

## 3. 文档视觉核验

三份样例DOCX通过 `render_docx.py` 渲染，实际逐页查看；最终各1页，中文可读、标题无装饰横线，无已观察到的裁切或重叠。三份文字PDF及1份扫描PDF通过Poppler渲染并实际查看。发现过一次OOXML命名空间兼容性问题，修复后重新渲染并加入回归检查。

这些结论仅针对虚构样例。实际Word字体替换、长合同、复杂表格、页眉脚注、编号、修订合并和签名保真未验。清洁导出是新建阅读快照，不是原Word无损往返。
