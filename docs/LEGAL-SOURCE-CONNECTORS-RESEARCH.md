# 法律信源与 MCP 接入调研

记录日期：2026-11-21（Asia/Shanghai）。分支：`feat/v0.3-evidence-retrieval`。

**结论：已经找到北大法宝和元典两家的官方法律 MCP 文档，可以列入接入候选；官方法源网站继续作为原文核对入口。公开提供 MCP 不代表免费、无需账户、已获本项目授权或能保证“绝对最新”。**

本轮仅查阅公开网页和官方文档。未注册、登录、取得 Token、调用任何法律 API/MCP、安装服务器、进入公司系统或运行应用测试。公开页面核验与接口运行验证分开记录。本文的候选建议属于产品判断，不是厂商性能、覆盖完整性或法律适用结论。

### 北大法宝：能力与授权要分别记录

官方聚合服务的公开索引说明法规/案例检索、法规版本链、条文沿革及引用核验；案例结果可能只包含题录和裁判结构段，不能当作整篇文书。文档也明确：未命中不是材料不存在，版本链不完整也不能证明法规没有其他版本。[S2]

其公开说明使用积分计费，提供服务开通状态、用量与余额查询工具；具体服务是否开启、单次积分和余额以获授权后的实际返回为准。不要把网页示例或索引里的账户数字当作用户账户事实。检索结果分页上限也应按当次工具说明确认。[S2–S3]

接入指南公开了例如 `https://apim-gateway.pkulaw.com/mcp-law-search-service`、`https://apim-gateway.pkulaw.com/mcp-law` 的配置。部署时应从官方控制台及当前文档取实际地址和可用工具，不能根据名称自行猜测其他端点。[S1]

仍待确认：账号权益、允许缓存或导出的内容范围、请求速率与并发、预算限制、失败计费、更新覆盖与延迟、留存及训练使用条款、机构授权和服务协议。本轮不作“不留存”“覆盖全部私募规则”或实时 SLA 承诺。

证券法条语义检索的官方文档支持时效、效力级别、地域与实施日期过滤，区分现行有效、失效、已被修改、部分失效和尚未生效。返回法条及所属法规信息；如需法规全文，另取法规详情。关键词法条检索还提供公布日期等过滤项。[S5–S6]

直接 REST API 示例使用 `X-API-Key`，MCP 配置使用 `Authorization: Bearer`；不能把两种调用方式的鉴权示例混用。响应示例中的业务 `code` 与 HTTP 状态码也应按实际接口规范分别处理。[S4–S5]

仍待确认：开通服务、积分与付费、请求限额、具体规则覆盖、增量更新机制与延迟、查询和响应留存、是否用于训练、返回内容使用及缓存许可。页面存在、文档近期生成和接口真实可用是三件不同的事。

## 3. 只读工具清单和当前不启用的能力

**可以进一步评估的只读工具类型：**法规/法条搜索、案例题录与详情、法规版本链、条文沿革、公开引文核对、授权服务列表与预算用量查询。实际开放哪些工具，需依据已获准服务及当时工具定义配置。

**当前不启用：**

- 法宝聚合工具中的反馈提交等对外写入能力。工具由供应商提供，不代表允许自动向第三方发送问题、材料或诊断信息。
- 元典企业检索、企业涉诉，以及带真实客户名检索公告或处罚的能力。现有项目约束只允许外发去标识化法律问题；若以后另立企业尽调场景，须单独明确范围和授权。
- 接收整份合同、客户名、内部策略或完整内部意见的查询、幻觉校验、在线调试和日志上报。
- 未经确认的公开第三方 MCP 代理。仅凭名字含“法律”“官方数据”不能确定来源、授权或数据处理方式。

计算机或浏览器查询可作为无适用接口时的补充方式。它不扩大数据权限，也不解除原站登录、验证码、使用条款或下载限制。结果仍需返回同一套来源记录，不能因为浏览器成功显示页面就标为“已核验法律结论”。

## 4. “最新”应成为可核对的记录

建议把“按当前时间查”和“按交易发生时点查”作为两个明确模式。新公布的文件可能尚未施行；今天已失效的版本可能仍与历史判断时点有关。不能把检索排序、网页更新日期或供应商的相似度分数当作适用性结论。

每条引用至少保留：

- 来源机构、数据服务商与官方原文链接，区分商业检索副本与制定/发布机关原文。
- 资料类别：法律法规、司法解释、监管规则、自律规则、指导性案例、参考案例、普通裁判；问答、书籍和编辑摘要另外标识。
- 文件名称、文号/案号/入库编号、条款位置、短引文，以及取得的是全文、片段、题录还是摘要。
- 公布时间、生效时间、失效或被取代时间、版本标签、修订关系与效力状态；未知字段保持未知。
- 查询模式、法域、判断时点、实际检索时间、原文读取时间、人工核验时间及核验说明。
- 查询条件、所用连接器、响应/文件摘要、失败或分页未完成状态，以及允许保存和再使用的范围。

建议结果状态为“候选资料 → 已读取原文 → 已核对引文 → 已核对时点 → 法务确认适用”。这些是不同状态；查到标题并不代表读过原文，引文匹配也不代表法律判断正确。法规与案例的版本/撤回变化可触发旧意见复核，不能自动替法务改结论或结案。

## 5. 本项目接入取舍

先复用公司已有、范围匹配的法律数据库授权，再比较北大法宝与元典的接口。现阶段将两家作为可替换候选，优先实现查询准备、证据记录、来源状态和官方跳转。没有 Token、权限或可用接口时，仍可完成手工来源登记与意见挂接。

企业内部制度、投委会文件、审批记录与历史合同属于另一条检索路径，不能和公共法律搜索共用出站数据包。它们可以支持内部事实或公司口径，但不自动成为法律依据；内部历史例外不自动成为通用标准。

本轮没有建立周期监测任务、没有实际外部法律检索结果或模型能力排名。恢复验证后，应以同组虚构问题逐项检查引文、时点、重大遗漏、访问受限和空结果表述，不能用接入成功替代结果质量验收。

## 迭代日志

- 来源：用户提出联网检索与公共 MCP/浏览器能力；上述官方文档和公开页面。
- 结论：北大法宝与元典作为法律 MCP 候选，官方网页作为核验入口；授权、运行和时效结论分别记录。

- 下一步建议：先建立统一检索任务与证据记录，再在获准范围内接通一家法律服务；沿用暂不验证安排。
