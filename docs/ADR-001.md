# ADR-001：先交付本地单体，保持文档、模型和检索接口可替换

状态：V0 采用 · 日期：2026-11-21

## 问题

投资法务需要按项目找到合同原件、识别未解决的问题并控制对外版本。首位用户沿用 Word，不需要工时、通用任务看板或复杂多服务安装。首轮使用虚构合同验证操作链路，不能以演示权限冒充真实公司权限。

## 决策

采用同源静态前端与 FastAPI 服务，SQLite 存业务台账和操作记录，原件由文档存储边界管理。前端只展示合同、审核意见、法源、交付物四个入口。模型建议经过统一的数据结构进入人工审核，V0 默认不调用外部模型。

### 不可变证据与可变状态分开

合同是业务对象，版本是不可变证据。每次上传建立新版本、文件摘要、原始文件名、类型、时间、解析状态；当前版只是指针。对文本的任何修改必须通过新版本上传完成。历史原件下载必须读指定版本，不能读取“当前文件”路径。

审查意见固定保留最初提出时的合同版本、条款号、原文片段和依据。新版本可建立“带入/待复核”关联；自动重定位失败要明确提示。意见的关闭需要人确认和说明，AI 只能给“可能已调整”提示。台账归档可恢复；签署件及审查证据不提供普通硬删入口。

交付物固定指向生成时的合同版本，记录格式、内容摘要、生成规则和检查结果。内部审核清单可以保留风险和谈判意见；对外清洁稿不混入内部意见，并须由人批准。批准针对该产物及其摘要，不能转移给后来重新生成的文件。下载 API 重新校验权限与批准状态，不信任前端按钮是否隐藏。

### 可替换边界

| 边界 | V0 | 未来适配条件 |
| --- | --- | --- |
| 文档存储 | 本地文件存储；服务端持有定位信息 | 公司文档库或对象存储；维持按版本取回、摘要校验、授权检查和备份能力；前端不拿存储密钥/路径 |
| 模型 | 离线演示规则/固定格式建议，明确标演示 | Gemini/Claude 适配同一输入/输出；经公司授权和盲测后启用；不得获得关闭问题或批准交付的权限 |
| 外部法源 | 官方跳转和手工记录 | 授权接口，输入仅去标识化法律问题；保留检索状态、来源、时点和准确引文 |
| 公司集成 | OpenAPI 描述与本地接口验证 | 身份映射、项目范围授权、服务账号权限和审计通过后接真实系统 |

API 至少保留项目范围授权决策的位置；导入要求支持幂等键，绑定项目、合同、请求内容摘要，重复同一请求返回原结果，同键不同内容拒绝。仅按权限列项目合同、导入新版本、下载已批准的外部交付件；不开放文件存储目录。

### V0 实现边界

代码中的项目范围令牌只保护 `/api/integration/` 三个公司接口；日常工作台 `/api/projects/` 是本机单人演示入口，没有企业身份登录或多用户 RBAC，不能对外绑定端口后宣称所有 API 都有项目授权。默认没有配置公司接口令牌，相关接口拒绝服务；测试可以注入只作用于临时数据的令牌。

模型边界当前只是统一协议与 `demo` 离线规则；Gemini、Claude 的真实适配、调用和质量评分尚未实现。外部法律检索准备接口只返回人工查询提示，不发出网络请求；勾选“已去标识化”只是人工声明，不等于实现了自动数据防泄漏检测。

批准失效当前按项目的审查修订号保守处理：项目内相关台账、版本、法源或意见变化可能要求已批准稿重新复核，尚未实现精细到每份交付物依赖项的失效计算。该策略宁可多复核；之后细化时不得遗漏版本、意见和依据变化。

上传版未选择带入意见、或把当前版回退后再次上传，仍须在验收中检查合同历史未决问题是否可见、批准时是否要求明确处理或接受。不能用“当前版没有意见”代替“全合同没有未解决的问题”。审批前也应有仅供内部复核的实际文件查看路径；对外交付 API 仍必须保持未批准拒绝下载。

## 选择理由

此方案优先验证业务不变量，减少首轮安装组件。现有企业库若已获得公司许可，将来可作为优先存储适配；Nextcloud 需要额外验证保留策略；OpenContracts 适合进一步评估文本定位与解析，整套引入增加运维面。对比和许可证据见 [RESEARCH.md](RESEARCH.md)。

## 代价与非目标

本项目要自行维护审批与审计逻辑；SQLite 不适合直接充当多主机共享数据库；本地单人演示不具备企业 SSO、完善 RBAC 或不可篡改审计保证。后续授权、恶意文件隔离、备份恢复和密钥管理均需明确验收。

不承诺重建 Word 修订，不承诺复杂 DOCX/PDF 排版保真，不让扫描 PDF 的空文本被误认成“无风险”。不自动签署、发邮件、公开部署或全量爬取法规。

## 重新评估触发点

当多人并发写入或公司统一文档库确定时，评估数据库/存储迁移；当真实需求确认必须保留精确页码与版面证据时，评估 OpenContracts 或独立解析器；当清洁稿转换损失造成明显复核成本时，优先补 Word 原生工作流及验收工具。上述变化不应改变版本不可变、意见由人结案和批准后交付三个原则。
